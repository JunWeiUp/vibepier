# VibePier：离开键盘，也能接着推进

> 发布用稿，尚未对外发布。正文中的能力以当前适配范围为准，下载入口须在首个公开 beta 验收后上线。封面为概念插画。

![VibePier：离开键盘，也能接着推进——概念封面](../../assets/launch/cover.zh-CN.png)

AI 编程有不少这样的时刻：任务还在跑，人已经离开了桌面。可能只是想看看进展，补一句要求，或者处理一个等待确认的问题。每次都回到电脑前，会打断手头的事。

VibePier 为这些短操作提供一个手机入口。它由 Android 应用、Mac 菜单栏应用和可选的自建中继组成，让你在手机上查看和继续适配的 AI 编程会话，也能控制 Mac 的快捷键与应用。项目采用 MIT 许可，手机遥控不需要额外购买 AU05 硬件。

## 把需要的下一步带到手机上

手机端可以按会话来源和项目浏览任务，阅读消息与展开的工具过程，保存草稿，并向支持的会话发送后续内容。遇到已经适配的审批或问答，可以直接处理；某个操作尚未接入时，应用会提示回到 Mac。

不同来源有不同边界。Codex 适配了原生会话和后续消息队列，但需要匹配桌面构建版本。Claude Code 会判断会话是否由桌面或终端占用，避免从手机另起进程把正在使用的终端会话分叉。

这些差异放在 README 和[兼容性说明](../COMPATIBILITY.md)里。不会因为列表能显示，就把所有操作都标成“支持”。

## 也保留顺手的桌面控制

首页提供六个可配置控制按键，可以设置通用快捷键，也可以按 Mac 应用分别配置。应用入口的位置保持稳定，当前应用的变化不会把整排按钮重新排序。

语音按钮以按住、松开为主要交互，默认使用 Mac 麦克风。需要从手机收音时，可以另行安装 BlackHole 2ch 并开启手机麦克风模式。录音和输入切换只在这次语音操作期间生效，结束后恢复原输入。手机音频通过蓝牙、本地 Wi-Fi 或协商成功的 UDP 直连传送；纯云中继不转发手机音频。

会话列表菜单也有“锁屏”和“解锁”。解锁是单独配置的功能，登录密码由 Mac 校验并保存在本地偏好，覆盖安装保留。手动解锁会保持解锁状态；临时为桌面操作解锁的流程则在操作结束后恢复锁屏。

## 按自己的网络部署

首次连接从蓝牙开始，手机自动向 Mac 请求授权，只需在 Mac 上确认。每台手机独立授权，之后可以选择蓝牙、本地 Wi-Fi 或自己的 WSS 中继。

中继是一个独立的 Go 服务，不需要数据库。README 给出了编译、systemd、Nginx、密钥导入和连接验证命令。配置在已授权蓝牙通道上同步到手机，不需要把中继密码粘贴到公开配置文件里。跨网络访问取决于你部署的服务和网络环境，项目不提供公共托管中继。

控制流量使用认证加密，模型服务的凭据留在 Mac。中继运营者仍能看到连接地址、时间和流量大小；手机也会保存经过加密的会话缓存与草稿。这些数据去向在[隐私文档](../PRIVACY.md)中逐项说明。

## 一个能继续维护的项目

仓库按 Mac、Android、中继、协议、素材和脚本组织，提供原生构建命令、共享协议样本和平台测试。新的 VibePier 图标、README 插画和封面随源码提供，原项目的 MIT 署名也完整保留。

首个 beta 面向 Apple silicon Mac 和 Android 手机。Mac 预览包尚未公证；桌面 AI 应用的接口也可能随版本变化。当前不提供 iOS、Windows 主机或远程开机能力，完整验收状态公开记录在项目清单中。

如果你的需求是在离开键盘时处理几个关键动作，可以从[安装与配对](../SETUP.md)开始。想部署自己的连接服务，直接看 [README 的中继命令](../../README.zh-CN.md#自建云中继部署命令与接入方法)；想参与适配、测试或文档维护，欢迎阅读[贡献说明](../../CONTRIBUTING.md)。
